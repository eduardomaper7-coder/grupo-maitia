# Grupo Maitía5 — Web editorial

Versión estática multipágina inspirada en el estilo editorial de la referencia facilitada: fondo negro, titulares grandes, collage fotográfico, bloques de color, fotografías tipo Polaroid y anotaciones manuscritas.

## Abrir la web
1. Descomprime el ZIP.
2. Abre `index.html` en el navegador.
3. Para probarla como servidor local: `python -m http.server 8000` dentro de la carpeta.

## Páginas incluidas
Inicio, casetas, fiestas populares, comuniones, barras y grifos, carpas, festivales y romerías, suministro para eventos, eventos privados, HORECA, colaboración Mahou, nosotros, galería, preguntas frecuentes, zonas de servicio, contacto, privacidad y cookies.

## Antes de publicar
- Confirmar teléfonos, email, razón social y dirección.
- Sustituir o validar las fotografías definitivas y sus derechos de uso.
- Confirmar autorización y normas de uso de la marca Mahou.
- Encargar la revisión de privacidad/cookies a un profesional.
- Añadir URL definitiva al sitemap y datos estructurados.

## Wix y dominio
El dominio puede seguir registrado o conectado en Wix. Esta web puede alojarse fuera de Wix y apuntar el dominio mediante DNS, o integrarse mediante las opciones de código/hosting disponibles en la cuenta contratada. Antes de cambiar DNS, guardar los registros actuales de correo y dominio.
